# Вайбкодер

Самостоятельное Android-приложение на базе Codex-режима из «Тени».
Весь проект находится в [`codex_android`](codex_android); сборка идёт через GitHub Actions.

- Отдельный пакет `ru.alim.newai`, устанавливается рядом с «Тенью».
- Внешний вид и поведение Codex-режима: верхняя панель диалогов, настройки,
  провайдеры и модели над полем ввода, прозрачный баббл reasoning, кнопка
  остановки вместо отправки, голосовой ввод DeepSeek и фирменная иконка.
- Несколько независимых диалогов. У каждого свой провайдер, модель, история и
  локальная задача; диалоги можно переключать и удалять.
- Провайдеры: GPT через вход ChatGPT, DeepSeek, AnyModel и любое количество
  OpenAI-совместимых API по ключу. Список моделей каждого провайдера
  загружается автоматически из `GET /models` и сохраняется на устройстве.
- Локальное окружение Python/Git/GitHub CLI/Codex, выполнение задач в foreground
  service, остановка, очередь/перебивание следующих сообщений и выдача файлов.
- Плавающее окно активности: reasoning и последний ответ поверх других
  приложений, скрывается при возврате в Вайбкодер.
- Ключи, введённые вручную, хранятся через Android Keystore /
  EncryptedSharedPreferences. Резервное копирование отключено.

## Сборка

Автоматическая сборка: [`.github/workflows/codex-apk.yml`](.github/workflows/codex-apk.yml).
Запускается при изменениях приложения и вручную через GitHub Actions.

Workflow `Build Vibecoder APK` проверяет Python-сервер и Android-код, готовит
runtime и шрифты, собирает APK и проверяет подпись. Результат — артефакт
`Vibecoder-signed-apk`.

Секреты GitHub Actions:

- `KEYSTORE_B64`
- `KEYSTORE_PASSWORD`
- `CERTIFICATE_ALIAS`
- `CERTIFICATE_PASSWORD`
- `GH_TOKEN` — автоматически передаётся Codex для GitHub CLI
- необязательно: `DEEPSEEK_API`, `ANYMODEL_KEY` — подхватываются как ключи
  соответствующих встроенных провайдеров

Алиас подписи определяется из keystore автоматически.

Локально: JDK 17, Android SDK 34, Gradle 8.13; затем
`python3 codex_android/scripts/prepare_runtime_assets.py` и
`gradle -p codex_android :app:assembleDebug`.

## Первый запуск

Нужен arm64-телефон с Android 8+. При первом запуске приложение распаковывает
окружение и скачивает закреплённые версии Codex и code-mode-host с проверкой SHA256.

В настройках Вайбкодера:

- войти в ChatGPT по подписке или добавить ключ DeepSeek/AnyModel;
- добавить своего провайдера: название, HTTPS-адрес API и ключ — модели
  подтянутся автоматически;
- вставить GitHub-токен для работы с репозиториями, PR и issues;
- включить плавающее окно и разрешить «Поверх других приложений»;
- выбрать «В очередь» или «Перебить» для сообщений во время задачи.

Если API провайдера не отдаёт `GET /models`, он не добавится — сначала нужно
исправить адрес или ключ. Для OpenAI-совместимых API адрес обычно заканчивается
на `/v1`.

Порты приложения: `18766` (сервер) и `18767` (прокси); у «Тени» они другие.
`targetSdk 28` сохранён из исходного runtime: Android запрещает исполнение
бинарников из приватного каталога при targetSdk 29+. Это APK для установки
напрямую, не конфигурация для публикации в Google Play.

Источник: Bolshoi, ветка `codex/ten-local-runtime`. Перенесены компоненты
Codex-режима; Telegram, почта, платежи, маршруты и прочие режимы «Тени» не включены.
