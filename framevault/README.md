# FrameVault

Android-приложение для обратимого преобразования файла любого формата в обычный ролик MP4 (H.264, 720 × 720, 24 кадра/с). Работает локально на Android 8.0 и новее.

1. Выберите **В видео** и укажите исходный файл. Если нужно шифрование, введите пароль.
2. Нажмите **Создать MP4** и сохраните видео. Его можно открыть в обычном плеере или переслать.
3. Для обратного преобразования выберите **Из видео**, укажите сохранённый MP4 и введите тот же пароль, если использовали его. Сохраните восстановленный файл.

Имя и содержимое исходного файла проверяются перед сохранением. Если указан пароль, записи шифруются AES-256-GCM с ключом, полученным через PBKDF2-HMAC-SHA256. С пустым полем содержимое доступно любому, у кого есть видео и декодер.

## Сжатие и размер

Данные хранятся в пикселях. Код Рида — Соломона исправляет ошибки чтения внутри кадра. Каждый пакет занимает три последовательных кадра, а контрольный пакет восстанавливает одну пропажу в каждой группе из восьми пакетов данных. Тест FFmpeg меняет разрешение и частоту кадров, повторно сжимает MP4 в H.264 и проверяет результат побайтно. Реальное перекодирование зависит от сервиса и выбранного пресета. Обрезка, наложения и сильное сжатие могут помешать восстановлению.

Чтобы сохранить MP4 без перекодирования в Telegram, отправьте его как файл. Примерная длительность составляет четыре минуты на 1 МиБ исходных данных. Для обработки и сохранения требуется дополнительное свободное место.

## Сборка

Требуются JDK 17, Gradle 8.13, Android SDK 35 и Build Tools 35.0.0. Для теста перекодирования нужен FFmpeg с libx264.

```sh
gradle :app:testDebugUnitTest :app:lintDebug :app:assembleDebug
```

В GitHub Actions workflow **FrameVault APK** публикует debug APK. При доступности секретов репозитория `KEYSTORE_B64`, `KEYSTORE_PASSWORD` и `CERTIFICATE_PASSWORD` он также публикует проверенный подписанный APK.
